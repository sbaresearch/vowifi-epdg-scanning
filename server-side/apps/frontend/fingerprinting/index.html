Fingerprinting

ePDGs that answer every IKEv2 handshake test the same way likely run the same software or similar configurations. Grouping their IPs by these fingerprints indicates which operators share an ePDG setup.

Snapshot from 27.10.2026. This page is static and not updated automatically. Code to perform fingerprinting is available on the GitHub Repository.

Method

How do we fingerprint?

  1. We take the packet captures from the Watchdog's scans. There's one capture per Diffie-Hellman group (14 in total, 768-bit MODP up to X25519), each holding the IKEv2 handshakes with the ePDGs.
  2. From each ePDG reply we take what the server has chosen via tshark: protocol, encryption, PRF (pseudo-random function), integrity and DH transforms (preserving the order), attribute types, the key exchange group and the nonce length. The nonce itself is random, so only its length is of interest.
  3. For every IP, the fields from all 14 captures are joined in ascending DH group order and hashed with MD5. We use this hash as the fingerprint.
  4. IPs with the same hash sent packets with identical fields mentioned in step 2, which hints that the same ePDG software, hardware or config is used. Only fingerprint clusters shared by two or more IPs are shown below.
