VoWiFi Watchdog

Project VoWiFi Watchdog aims to monitor the global VoWiFi landscape with automated scanning and analysis of worldwide ePDG infrastructure and IKEv2 Diffie-Hellman handshakes. Its main goal is to provide insights accessible to all, researchers, operators and the general public in an intuitive and interactive way.

Overview

What this is all about

Today, there exists a lack of transparency for subscribers to validate and find out which encryption methods operators use to secure WiFi calling. This Watchdog aims to close this gap by giving everybody the possibility to gain insight into and educate themselves about the service they use.
By disclosing the full dataset, even further analysis can be conducted across the data.


This project is based on the paper Diffie-Hellman Picture Show: Key Exchange Stories from Commercial VoWiFi Deployments1. This project runs an automated pipeline that discovers ePDG infrastructure, then executes multiple IKEv2 handshake tests and exposes the Data through an API and map UI.
A recent version of this project's source code is available on the Watchdog GitHub Repository, where further technical details about this project can be found.

Discovery

Generates all possible ePDG domains with MCC and MNC combinations and then runs DNS scans to identify active VoWiFi targets.

Scanning

Multiple IKEv2 handshake variants are made against discovered targets to evaluate operator support, downgrade tolerance, and response quality.

Storage

Scan results are normalized, analyzed and stored for later serving via API and visualization.

Visualization

Visualizations are provided to give intuitive insights into the global VoWiFi landscape, with a special focus on handshake support.
